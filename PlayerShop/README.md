# PlayerShop / 玩家商店

Minecraft Bedrock 26.45 箱子玩家商店。当前版本：**v1.0.0**。

## 核心交互

- 只支持普通箱子 `minecraft:chest`。
- 创建：先把商品放进箱子，再手持 **橡木告示牌** 对着箱子放置；确认后自动进入商品价格设置。
- 告示牌固定显示：`“卖家”的商店`。
- 一个商店可以出售多种商品，每种商品单独定价。
- 新放入箱子的商品不会自动出售，必须由店主进入管理 GUI 设置价格。
- 已登记商品直接往箱子里补货即可，库存以箱子实时内容为准。
- 店主普通点击商店箱子：打开原版箱子补货；潜行点击：进入商店管理。
- 买家点击：打开购买 GUI。
- 背包放不下的购买物品会保持原 ItemStack 数据，并以类似原版 `/give` 溢出的方式从玩家附近喷出。

## 双箱

- 创建时如果已经是大箱子，两个箱子会作为一个商店库存。
- 单箱商店后续由店主在旁边放第二个普通箱子形成大箱时，会自动把第二半加入同一个商店并同步保护。
- 其他玩家不能给别人的商店箱子扩容。

## 商品识别

商品模板会考虑物品类型、自定义名称、Lore、附魔、耐久和药水信息。耐久不同的装备视为不同商品，避免买家看到满耐久商品却拿到残损装备。

## 共享金币

使用全服 scoreboard objective：`server_money`。

参与者格式：`u:<lowercase player name>`。

这套金币不属于 PlayerShop 或 myLand 任意单个插件，因此：

- PlayerShop 单独安装也能正常使用。
- myLand 卸载不会让金币消失。
- 后续签到、任务、悬赏等插件可以继续复用同一经济协议。

初始余额：20,000 金币。默认成交税：0%。

## myLand 联动

- 没有 myLand：PlayerShop 独立工作，商店箱子仍由 PlayerShop 自己保护。
- 检测到 myLand：创建箱子商店时要求箱子位于创建者自己的地皮。
- 已注册商店箱子和商店告示牌由 PlayerShop 优先管理，myLand 不再把它们当普通容器/普通方块处理。

## 指南针协同

共享 heartbeat objective：`gui_bridge`。

插件标识：

- `myland`
- `survival`
- `shop`

菜单请求通过短期玩家 tag 发送，不通过跨包自定义命令调用。

## 保护

保护由 PlayerShop 自身提供，不依赖 myLand：

- 非店主不能打开原版商店库存。
- 非店主不能破坏商店箱子或告示牌。
- 店主需要从管理 GUI 关闭商店后才能拆除。
- 爆炸不会破坏商店块。
- 活塞检测到推动商店块时会阻止持续推动。

## 管理员

管理员中心提供：全服商店、搜索玩家/商店、成交税、默认商店数量上限、全服最近交易。

直接命令仅保留：

- `/shop:menu`
- `/shop:help`
- `/shop:admin`（OP）
